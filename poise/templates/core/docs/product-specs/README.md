# Product Specs

Feature specifications — written before implementation, updated if scope
changes, never deleted after release (move to `archived/` instead).

Each spec answers:
- What problem does this solve?
- What does the API / interface look like?
- What are the acceptance criteria?
- What is explicitly out of scope?

Agents read specs to understand intent before implementing. If there is
no spec for the feature you're about to build, write one first.
